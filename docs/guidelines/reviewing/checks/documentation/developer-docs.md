# Checks: developer-docs

Verifies [authoring/documentation/developer-docs](../../../authoring/documentation/developer-docs.md). Tier = lowest [risk tier](../../../core/risk-tiers.md) at which to check.

| Check | Rule | Tier |
| --- | --- | --- |
| Does each document live next to what it describes? | [keep developer docs with the code](../../../authoring/documentation/developer-docs.md#keep-developer-docs-with-the-code) | Medium |
| Do public elements have doc comments stating their contract? | [write contracts as doc comments](../../../authoring/documentation/developer-docs.md#write-contracts-as-doc-comments) | Medium |
| Is API reference generated from the code? | [write reference material in the code](../../../authoring/documentation/developer-docs.md#write-reference-material-in-the-code) | Medium |
| Are reasons in decision records or design docs, linked from the code? | [record why in decisions and design docs](../../../authoring/documentation/developer-docs.md#record-why-in-decisions-and-design-docs) | Medium |
| Is there a runnable contributor document? | [give contributors a way in](../../../authoring/documentation/developer-docs.md#give-contributors-a-way-in) | Low |
| Is there a structure overview for multi-module projects? | [describe structure for newcomers](../../../authoring/documentation/developer-docs.md#describe-structure-for-newcomers) | Low |

## Blocking

All optional; raise as should fix when contributors cannot get started.
