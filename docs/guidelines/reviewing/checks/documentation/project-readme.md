# Checks: project-readme

Verifies [authoring/documentation/project-readme](../../../authoring/documentation/project-readme.md). Tier = lowest [risk tier](../../../core/risk-tiers.md) at which to check.

| Check | Rule | Tier |
| --- | --- | --- |
| Does it say what the project is and who it is for? | [say what it is and who it is for](../../../authoring/documentation/project-readme.md#say-what-it-is-and-who-it-is-for) | Low |
| Is there a verified path to a first success? | [get to a first success quickly](../../../authoring/documentation/project-readme.md#get-to-a-first-success-quickly) | Low |
| Does it link to depth instead of containing it? | [link instead of containing](../../../authoring/documentation/project-readme.md#link-instead-of-containing) | Low |
| Does it say how to get help, contribute, and the license? | [say how to get help and contribute](../../../authoring/documentation/project-readme.md#say-how-to-get-help-and-contribute) | Low |
| Are status and support stated? | [state status and support](../../../authoring/documentation/project-readme.md#state-status-and-support) | Low |

## Blocking

Blocking: setup steps that do not work. Others are optional.
